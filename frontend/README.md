# Frontend README

This is the frontend scaffold for DeepTruth (React + TypeScript + Vite + Tailwind).

To run locally:

1. cd frontend
2. npm install
3. copy .env.example to .env and set VITE_API_BASE_URL to your API endpoint (e.g. http://localhost:8000)
4. npm run dev

The app expects the backend API at `http://localhost:8000` during local development. The frontend uses the same base URL from `VITE_API_BASE_URL`.
